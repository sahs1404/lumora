# CV building points (optional, makes the map come alive)

One CSV per village, named `<village_id>.csv` (e.g. `demo_a.csv`), with columns:

lat,lon,type
1.30012,36.80045,home
1.30020,36.80102,business

`type` is `home` or `business` from the CV classifier. The map plots homes in light blue and likely businesses in amber.
